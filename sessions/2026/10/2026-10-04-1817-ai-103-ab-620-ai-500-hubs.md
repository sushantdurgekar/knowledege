## Key points learned (platform changes to remember, checked 2026-10-02)
- Foundry agents (July 2026): new agents get their own Entra agent identity and a stable endpoint at creation; *agent applications* are the legacy publish model. Only MCP and A2A tools authenticate as the agent identity today.
- Foundry Agent Consumer = least privilege for agent endpoints; legacy agent applications need Foundry User (`applications/invoke/action`). Publishing to Teams also needs Azure Bot Service Contributor.
- Foundry workflows (visual designer) retire 1 Dec 2026 → Microsoft Agent Framework (or Logic Apps / A2A).
- Content Understanding: pro mode lived only in the retired 2025-05-01-preview API (successor: agentic mode, preview); confidence and grounding come only from document analyzers.
- Azure OpenAI On Your Data retires 14 Oct 2026 → Foundry Agent Service + Foundry IQ (affects AB-620's "Azure AI Search with Foundry" skill).
- Model lifecycle: gpt-4.1-nano 14 Oct 2026; gpt-4o-transcribe (2025-03-20) and sora-2 (2025-12-08) 15 Oct 2026; gpt-image-1 23 Oct 2026; o3/o4-mini/o3-mini 19 Nov 2026; gpt-4.1/gpt-4.1-mini deprecated (new subscriptions can't deploy them).
- LangGraph human-in-the-loop: `interrupt()` + durable checkpointer + `Command(resume=...)`; static `interrupt_before` is for debugging.
- Local `evaluate()` and `RedTeam` (azure-ai-evaluation) target Foundry classic projects; new Foundry projects use the cloud evals API.
