# Data Structures & Algorithms: levels L1–L4

Keys follow your proficiency-framework format: `L1-03` is the third topic at L1. Skills are listed under each topic; each becomes a lesson or part of one when the hub is built. *(verify)* marks facts to re-check at build time.

## L1 Foundation

*Level definition:* Builds foundational knowledge and practical skills; handles defined tasks with guidance and follows standard practice.

**Outcome:** Analyse complexity and solve easy problems with arrays, hashing, two pointers, stacks, queues and binary search.  
**Time:** about 50–70 hours · **Certification:** No credible certification; milestone = 40 easy + 20 medium problems · **Hub:** `hubs/dsa-l1-foundation-hub.html`

- [ ] amortised analysis intro
- [ ] reading constraints

### L1-02 Arrays and strings
- [ ] Static vs dynamic arrays
- [ ] prefix sums
- [ ] in-place updates

### L1-03 Hashing
- [ ] Hash maps and sets
- [ ] counting
- [ ] collisions at a high level

### L1-04 Two pointers and sliding window
- [ ] Opposite-end and same-direction pointers
- [ ] fixed and variable windows

### L1-05 Stacks and queues
- [ ] LIFO/FIFO
- [ ] monotonic stack
- [ ] deque

### L1-06 Linked lists
- [ ] Singly/doubly
- [ ] reversal
- [ ] fast and slow pointers

### L1-07 Recursion
- [ ] Base case and recursive case
- [ ] call stack
- [ ] recursion trees

### L1-08 Sorting and binary search
- [ ] Merge sort, quick sort
- [ ] built-in sort
- [ ] binary search and search on the answer

**Capstone.** **Mini DS library:** implement dynamic array, linked list, stack, queue and hash map in Python with tests and Big-O notes; solve 40 easy problems.

**Evidence to mark L1 complete:** capstone repo or app link + hub mastery ≥ 80% on every topic + a reviewed write-up.

**Outcome:** Solve medium interview problems with trees, heaps, graphs, backtracking and core DP.

**Outcome:** Handle hard problems: advanced DP, shortest paths, range queries, strings and number theory; reach a solid contest rating.  
**Time:** about 100–130 hours · **Certification:** None; milestone = contest rating · **Hub:** `hubs/dsa-l3-specialist-hub.html`
