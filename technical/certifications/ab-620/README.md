# AB-620: Microsoft Certified: AI Agent Builder Associate

AB-620 (*Designing and Building Integrated AI Agent Solutions in Copilot Studio*) tests whether you can plan, build, extend, integrate, evaluate and ship **Copilot Studio** agents: topics and adaptive cards, agent flows, knowledge, tools and MCP, multi-agent designs with Foundry, Fabric and A2A, Azure integration, evaluation and ALM. Integrate and extend is the biggest domain (40–45%).

## Start here
1. Open the **AB-620 Study Hub** (https://claude.ai/artifact/DfeAjDjaTCgtf36RSKeSSS) and take the 15-minute diagnostic.
2. Work [roadmap.md](roadmap.md) top to bottom; each module has a concept note below for revision.
3. Log mocks in [readiness.md](readiness.md); book only when its gate is met.
