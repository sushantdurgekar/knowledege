# Data Structures & Algorithms

Problem-solving from Big-O to contest algorithms, taught in **Python and JavaScript** side by side.

- **L1 Foundation hub** (built 2026-10-09): [open the hub](https://claude.ai/artifact/SWv6N1Uh2oiFNH1mxefcNr) · offline copy [`hubs/dsa-l1-foundation-hub.html`](hubs/dsa-l1-foundation-hub.html). Flashcards: deck `dsa-l1`, parked until you start (`python _meta/tools/activate_deck.py dsa-l1`).
- **L2 Proficient hub** (built 2026-10-09): [open the hub](https://claude.ai/artifact/DQhszKFoe8qbiNbSpWkqM5) · offline copy [`hubs/dsa-l2-proficient-hub.html`](hubs/dsa-l2-proficient-hub.html). Trees, heaps, tries, graphs, union-find, backtracking, DP, greedy and bits. Flashcards: deck `dsa-l2`, parked until you start (`python _meta/tools/activate_deck.py dsa-l2`).
- **L3 Specialist hub** (built 2026-10-11): [open the hub](https://claude.ai/artifact/JfuakQWBwAvSgLi1rcuJUk) · offline copy [`hubs/dsa-l3-specialist-hub.html`](hubs/dsa-l3-specialist-hub.html). Shortest paths, MSTs, bridges and Euler paths, interval/bitmask/tree DP, prefix sums and monotonic queues, Fenwick and segment trees, KMP/Z/hashing, number theory, games and digit DP. Flashcards: deck `dsa-l3`, parked until you start (`python _meta/tools/activate_deck.py dsa-l3`).
- **L4 Expert hub** (built 2026-10-12): [open the hub](https://claude.ai/artifact/DxduaMdo2n5kqrt3We8PPZ) · offline copy [`hubs/dsa-l4-expert-hub.html`](hubs/dsa-l4-expert-hub.html). SCCs and 2-SAT, max flow and min cut, matching and assignment (Hungarian, min-cost flow), binary lifting and LCA, suffix arrays, sparse tables, √n blocks, Mo's algorithm and skip lists, exact geometry, matrix power and probability, DP optimisations (convex hull trick, divide and conquer, SOS), stress testing and problem setting. Flashcards: deck `dsa-l4`, parked until you start (`python _meta/tools/activate_deck.py dsa-l4`).
