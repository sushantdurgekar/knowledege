## Suggested exam sequence (fits the build queue)

1. **AI-103** (hub ready) → **AI-500** (needs AI-103). AB-620 optional alongside.
2. **PCEP → PCAP** during Python L1–L2 (check the new 30-03 / 31-04 versions first).
3. **PL-300** at the end of Power BI L2; **Qlik Sense Data Architect** or **Business Analyst** certification at Qlik L2.
4. **DP-800** at SQL L3 (pairs well with AI-103 knowledge); **DP-600** at Power BI L3.
5. Web stack: JSE/JSA optional; certificates.dev exams only if an employer values them. Projects are the stronger signal.
6. **CKAD** at Docker L3 if you go the platform route.

Reminder: Microsoft role-based certs renew yearly via a free online assessment.
